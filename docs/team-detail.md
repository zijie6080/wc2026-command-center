# 国家队详情页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/teams/:id`
> **页面定位:** 一支国家队的完整档案——从历史到本届、从数据到阵容的全维度视图
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|----------|
| 身份识别 | 进入页面 1 秒内识别国家队身份 | 国旗 + 队徽 + 队名首屏可见 |
| 晋级感知 | 用户一眼看清当前出线形势 | 小组排名 + 晋级状态首屏可见 |
| 阵容可浏览 | 26 人大名单可快速扫描 | 按位置分组 + 号码排列 |
| 赛程串联 | 从球队页无缝跳转到比赛详情 | 每场赛程均可点击 |

##### 左区域 — 球队身份

| 元素 | 作用 | 细节 |
|------|------|------|
| **国旗** | 即时国家识别 | 大尺寸国旗图标(48px) |
| **队徽** | 足协官方标识 | 官方队徽矢量图(64×64px) |
| **队名(中文)** | 本地化队名 | "阿根廷国家足球队" |
| **昵称** | 球队文化符号 | "Albiceleste (蓝白军团)" |
| **FIFA 排名卡片** | 实力快速感知 | 大号数字 + 排名文字，排名上升显示绿色▲，下降显示红色▼ |
| **主教练** | 战术决策者标识 | 姓名可点击(未来可跳转教练详情页) |
| **队长** | 场上领袖标识 | 姓名可点击跳转球员详情页 |
| **世界杯参赛次数** | 历史积淀 | "19次"(含本届) |
| **最佳战绩** | 历史荣耀 | "冠军(3次)"，鼠标悬停显示年份 tooltip |

##### 右区域 — 荣耀与场馆

| 元素 | 作用 | 细节 |
|------|------|------|
| **世界杯冠军 ★** | 最高荣誉展示 | 金色星星 + 次数 + 夺冠年份(垂直排列) |

| **操作按钮** | ⭐收藏 / 🔗分享 / 📅全部赛程 / 🧮晋级分析 | 核心交互入口 |

## 七、交互行为汇总

### 7.1 页面级

| 交互 | 行为 |
|------|------|
| **⭐ 收藏** | 收藏该球队，同步到"我的收藏"页，首页推荐优先展示 |
| **🔗 分享** | 生成球队数据卡片图片 → Twitter/Facebook/WhatsApp/复制链接 |
| **📅 全部赛程** | 滚动到"赛程"标签页 |
| **🧮 晋级分析** | 跳转到 AI 预测中心，自动筛选该球队 |

### 7.2 内容级

| 交互 | 行为 |
|------|------|
| **点击积分榜其他球队** | 跳转该球队详情页 `/teams/:id` |
| **点击近期战绩卡片** | 跳转该场比赛详情页 `/matches/:id` |
| **点击球员卡片** | 跳转球员详情页 `/players/:id` |
| **点击主教练姓名** | 展开教练完整资料(或未来跳转教练详情页) |
| **点击历史世界杯** | 展开该届详细赛程 |

### 7.3 键盘快捷键（桌面端）

| 快捷键 | 行为 |
|--------|------|
| `1-6` | 切换页内标签 (1=概览, 2=阵容, 3=数据, 4=赛程, 5=历史, 6=新闻) |
| `S` | 收藏/取消收藏 |
| `Esc` | 关闭弹窗 |
