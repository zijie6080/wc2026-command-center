# 比赛详情页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/matches/:id`
> **页面定位:** 平台核心页面——承载 70%+ 用户停留时长，覆盖赛前/赛中/赛后全生命周期
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|------|
| 实时感知 | 比分和事件更新延迟 < 3 秒 | 与官方数据源对比时差 |
| 三态无缝 | 赛前→赛中→赛后自动切换，用户无感知 | 状态切换 < 500ms |
| 数据可扫读 | 核心统计数据一瞥即懂 | 进度条 + 数字对比一目了然 |
| 事件可回溯 | 任意事件可点击查看详情 | 事件时间线完整可交互 |

### 3.2 模块逐一详解 — 赛中视图

---

#### ① 顶部全局导航栏 (Navbar — 56px, fixed)

与全站一致，"比赛"标签高亮，显示进行中比赛数量角标。

---

#### ② 比赛导航切换条 (Match Switcher — 40px, sticky)

```
┌───────────────────────────────────────────────────────────────────────────────┐
│  ◀ 上一场   │  6月4日 周四  │  阿根廷 vs 巴西  ● LIVE  │  下一场 ▶           │
└───────────────────────────────────────────────────────────────────────────────┘
```

| 元素 | 作用 | 交互 |
|------|------|------|
| **◀ 上一场** | 切换到当天前一场比赛 | 点击跳转 `/matches/:prevId`，键盘 ← |
| **日期** | 当天日期信息 | 静态展示 |
| **对阵标题** | 当前比赛对阵 + LIVE 指示灯 | 呼吸灯动画 |
| **下一场 ▶** | 切换到当天后一场比赛 | 点击跳转 `/matches/:nextId`，键盘 → |
| **无上一场/下一场** | 箭头变灰 disabled | 不可点击 |

---

```
└───────────────────────────────────────────────────────────────────────────────┘
```

| 元素 | 作用 | 细节 |
|------|------|------|
| **国旗+队名** | 主客队标识 | 大尺寸国旗(40px) + 缩写 + 全名 |
| **比分** | 核心信息 | 48px 大字号，进球时数字翻转动画(300ms)，闪烁 3 次 |
| **比赛时钟** | 实时比赛时间 | 精确到秒，从开球起计时，伤停补时额外显示"+N" |
| **进球摘要** | 每队进球时间 | 小字列出每个进球的时间，帮助回忆 |
| **LIVE 指示灯** | 进行中状态 | 红色呼吸灯动画(1.5秒周期) |
| **伤停补时** | 半场/全场补时 | 裁判举牌后显示，背景黄色高亮 |
| **操作按钮** | ⭐收藏/🔔提醒/🔗分享/💬聊天室(实时在线人数)/📊数据面板 |

**比赛时钟行为：**
- 上半场：0'00" ~ 45'+N'（从 0 往上计数）
- 中场休息：显示"中场休息" + 下半场倒计时
- 下半场：45'00" ~ 90'+N'
- 加时赛上半场：90' ~ 105'+N'
- 加时赛下半场：105' ~ 120'+N'
- 点球大战：显示"点球大战" + 实时比分

## 七、交互行为汇总

### 7.1 页面级

| 交互 | 行为 |
|------|------|
| **比赛切换** | ← 键盘左箭头/右箭头 → 切换到上/下一场比赛 |
| **自动状态切换** | 赛前→赛中→赛后自动检测并切换视图，无需手动刷新 |
| **比分实时推送** | WebSocket 推送比分变化，无需轮询 |
| **进球震动(移动端)** | 进球时手机短震动(tactic feedback) |

### 7.2 内容级

| 交互 | 行为 |
|------|------|
| **点击事件卡片** | 展开完整事件详情(进球→射门位置图；换人→上下场球员数据对比) |
| **点击球员名** | 跳转球员详情页 `/players/:id` |
| **点击球队名/国旗** | 跳转球队详情页 `/teams/:id` |
| **点击查看回放** | 弹出视频播放器(嵌入或跳转) |
| **悬停统计指标** | 显示 Tooltip 解释 |
| **点击 💬 聊天室** | 展开/跳转实时聊天室 |

### 7.3 快捷键

| 快捷键 | 行为 |
|--------|------|
| `←` `→` | 切换比赛 |
| `1-5` | 切换页内标签 |
| `F` | 收藏/取消 |
| `S` | 分享 |
