# 首页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/`
> **页面定位:** 世界杯观测平台"控制塔"——用户在5秒内掌握"正在发生什么"
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|----------|
| 态势感知 | 一眼看到正在进行的比赛和比分 | 进入页面后 3 秒内可识别 |
| 快速导航 | 一键触达积分榜、赛程、球队等核心页面 | 任何核心入口不超过 2 次点击 |
| 信息聚合 | 新闻、数据快照、焦点故事一站式呈现 | 首屏覆盖 5 种以上信息类型 |
| 个性化 | 根据关注球队定制内容优先展示 | 登录用户首屏差异率 > 60% |

### 2.2 模块逐一详解

---

#### ① 顶部全局导航栏 (Global Top Navbar — 56px)

```
┌──────────┬────────────────────────────────┬──────────┬──────────┬─────────────┐
│🏆 WC2026 │  🔍 搜索球队、球员、比赛...    │ 🌐 EN ▼ │ 🌙 ☀️   │ 👤 登录/头像 │
│ Command  │                                │          │          │             │
│ Center   │                                │          │          │             │
├──────────┴────────────────────────────────┴──────────┴──────────┴─────────────┤
│  ● 首页  │  ⚽ 比赛  │  📅 赛程  │  🏆 积分榜  │  👥 球队  │  ⭐ 球员  │  📰 新闻  │
└───────────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 作用 | 交互 |
|------|------|------|
| **Logo + 标题** | 品牌标识，建立信任感；点击回到首页 | 点击 → 返回 `/` |
| **全局搜索框** | 快速搜索球队/球员/比赛/新闻，支持模糊匹配和自动补全 | 输入即搜索，`Ctrl+K` 快捷键呼出 |
| **语言切换** | 切换 8 种语言（EN/中文/ES/FR/AR/PT/JP/KO），影响全站内容 | 下拉选择 → 即时切换 |
| **主题切换** | 深色模式 / 浅色模式 / 跟随系统，深色模式为默认（观赛场景） | 点击循环切换 |
| **用户区** | 未登录：显示"登录"按钮；已登录：头像 + 下拉菜单（我的收藏/设置/退出）| 点击展开 |
| **主导航标签** | 7 个一级导航入口，当前页高亮（●），比赛标签在赛事期间显示进行中数量角标 | 悬停展开二级菜单，点击跳转 |

#### ② 突发新闻滚动条 (Breaking News Ticker — 32px)

```
┌───────────────────────────────────────────────────────────────────────────────┐
│  🔴 BREAKING: 梅西训练中轻伤，出战成疑 | 内马尔确认首发 | 法国队抵达多哈...  │
└───────────────────────────────────────────────────────────────────────────────┘
```

| 属性 | 说明 |
|------|------|
| **作用** | 全球最高优先级的突发新闻实时滚动展示，不让用户错过任何关键动态 |
| **内容** | 伤病更新、首发剧透、天气影响、官方公告等"必须知道"的信息 |
| **行为** | 从右向左自动滚动（marquee），鼠标悬停暂停，点击展开完整新闻 |
| **数据源** | 编辑团队推送 + AI 自动抓取关键新闻 |
| **显示规则** | 有突发新闻时显示，无新闻时自动隐藏节省空间 |
| **优先级** | 只有"Breaking"级别新闻才进入此条，确保信息权重 |

| **未开始卡片** | 对阵双方 + 大型倒计时（天-时-分-秒），营造期待感 |
| **已结束卡片** | 最终比分 + 最佳球员 + 赛后战报入口 |

| **轮播指示器** | 底部圆点导航，显示当前位置，支持点击/拖拽切换，显示相邻卡片标题 |
| **背景** | 每张卡片使用不同球队主色调渐变背景，增强视觉冲击力和辨识度 |

## 五、交互行为定义

### 5.1 页面级交互

| 交互 | 触发方式 | 行为 |
|------|----------|------|
| **下拉刷新** | 页面顶部下拉 | 刷新全部数据（比分/赛程/新闻），顶部显示刷新指示器旋转动画 |
| **自动刷新** | 每 30 秒 | 仅更新进行中比赛的比分和事件，不触发页面闪烁 |
| **回到顶部** | 滚动超过 800px 后显示浮动按钮 | 平滑滚动回页面顶部 |
| **比赛通知弹窗** | 关注的球队进球/红牌时 | 浏览器通知（需授权）+ 页面内 Toast 提示 |

### 5.2 比赛卡片交互

| 交互 | 行为 |
|------|------|
| **点击卡片任意位置** | 跳转比赛详情页 `/matches/:id` |
| **悬停卡片（桌面端）** | 卡片轻微放大(scale 1.02) + 显示阴影，展示更多信息 |
| **点击 🔔 提醒按钮** | 未登录→引导登录；已登录→设置推送通知→按钮变为 ✅ |
| **进球动画** | 比分数字翻转效果 + 卡片边框橙色呼吸灯闪烁 3 秒 |

### 5.3 Hero 横幅交互

| 交互 | 行为 |
|------|------|
| **自动轮播** | 5 秒间隔自动切换到下一张卡片 |
| **手动切换** | 点击左右箭头 / 拖拽 / 点击轮播指示器圆点 |
| **点击"进入直播"** | 跳转比赛详情页（赛中视图） |
| **悬停暂停** | 鼠标悬停时停止自动轮播，移开后恢复 |

### 5.4 快捷键 (桌面端)

| 快捷键 | 行为 |
|--------|------|
| `Ctrl + K` | 聚焦全局搜索框 |
| `Ctrl + 1~7` | 快速跳转主导航（1=首页, 2=比赛, 3=赛程, 4=积分榜, 5=球队, 6=球员, 7=新闻） |
