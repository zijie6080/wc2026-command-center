# 比赛中心原型设计 — World Cup 2026 Command Center

> **页面路径:** `/matches`
> **页面定位:** 比赛维度的全局视图——快速浏览、筛选、定位所有比赛
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|----------|
| 一屏概览 | 所有进行中比赛一眼可见 | 首屏可见 ≥ 4 场 Live 比赛 |
| 快速筛选 | 按状态/日期/阶段秒级切换 | 筛选操作 < 1 次点击 |
| 状态感知 | 比赛状态（进行中/已结束/未开始）一目了然 | 卡片颜色+图标双重区分 |
| 无缝导航 | 从列表到比赛详情再返回，路径最短 | 详情页→列表页 < 1 次点击 |

#### ⑤ 比赛卡片列表 (Match Card List — 主内容区，可滚动)

这是比赛中心的核心模块。比赛按日期分组，每组以日期标题分隔。

##### 5.1 日期分组标题

```
┌─ 2026年6月4日 星期四 · 小组赛第1轮 · 4场比赛 ─────────────────────────────────┐
```

| 作用 | 作为日期分隔符，让用户快速扫描不同日期的比赛 |
|------|------|
| **内容** | 完整日期 + 星期 + 赛事阶段 + 当天比赛总数 |
| **交互** | 点击可折叠/展开当天比赛列表（默认展开） |
| **折叠状态** | 点击后收起卡片，仅显示标题行，右侧显示比分摘要 |

| 编号 | 元素 | 说明 |
|------|------|------|

## 五、筛选组合行为

### 5.1 筛选标签联动

```

│  用户选择"进行中"标签                                            │

│      └── ⑤ 卡片列表：仅显示 status='finished' 的比赛            │
│                                                                 │
│  用户选择"小组赛"标签                                            │

└─────────────────────────────────────────────────────────────────┘
```

### 5.2 多选筛选规则

| 规则 | 说明 |
|------|------|
| **状态标签互斥** | "进行中""今日""已完成""即将"之间互斥，选择其一取消其他 |
| **阶段标签叠加** | "小组赛""淘汰赛"可与状态标签叠加（如"进行中 + 淘汰赛"） |
| **球队筛选独立** | 从"更多"中选择球队后，显示为第 8 个标签，点击 × 取消 |
| **日期选择独立** | 日期选择器与筛选标签独立工作，可叠加（如"6月4日 + 小组赛"） |
| **重置逻辑** | 点击"全部"清除所有筛选，回到默认状态 |

## 六、空状态与边界场景

### 6.1 空状态设计

| 场景 | 展示内容 |
|------|----------|
| 当前无进行中比赛 | 筛选栏"进行中"角标为 0，切换后显示空状态："当前无进行中比赛 ⚽ 查看今日赛程 →" |
| 当前筛选无结果 | 插画 + "没有符合条件的比赛 🤔" + "试试调整筛选条件？[清除筛选]" |
| 所有比赛已结束 | 显示最后一次比赛结束时间 + "世界杯 2026 已落幕 🏆 [查看冠军之路 →]" |
| 网络加载失败 | "⚠️ 数据加载失败 [重试] [查看缓存数据]" |

### 6.2 边界场景

| 场景 | 处理方式 |
|------|----------|
| 比赛进行到加时赛 | 时间显示"加时赛 105'"，比分包括加时进球 |
| 点球大战 | 卡片自动扩展显示点球比分，如"PK(4:3)" |
| 比赛延期 | 卡片状态变为"延期"，显示延期原因（如"天气原因"） |
| 比赛取消 | 卡片变灰半透明（opacity 0.6），显示"取消"标签 |
| 跨日期筛选 | 日期选择器支持范围选择（点击"6/4-6/7"范围） |

## 七、交互行为汇总

### 7.1 页面级
