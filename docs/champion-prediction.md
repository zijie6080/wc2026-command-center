# 夺冠预测页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/predictions/champion`
> **页面定位:** 冠军之路可视化——AI预测+晋级路线+球队夺冠概率一览
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 |
|------|------|
| 夺冠概率可视 | 一眼看清哪支球队最被看好 |
| 晋级路径可追踪 | 从小组赛到决赛的每步概率均可查看 |
| AI 透明可信 | 展示预测模型的依据和准确率，建立用户信任 |
| 互动探索 | 用户可点击任意球队查看其详细晋级概率 |

| 元素 | 说明 |
|------|------|
| **奖牌图标** | 🥇🥈🥉 前三名用奖牌图标，第 4-5 用数字 |
| **国旗+队名** | 大尺寸国旗(40px) + 队名(中/英) |
| **夺冠概率** | 大字号百分比，颜色深浅与概率成正比 |
| **概率条** | 可视化进度条，主队色填充 |
| **交互** | 点击任意卡片 → 滚动到该球队的详细分析 |

| **交互** | 点击任意球队 → 高亮其最可能路径；悬停显示具体概率 |
| **虚线/实线** | 已确定的比赛用实线，预测用虚线 |
