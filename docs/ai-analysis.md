# AI 分析中心原型设计 — World Cup 2026 Command Center

> **页面路径:** `/predictions`
> **页面定位:** AI 驱动的赛事预测与分析中心——从比赛预测到球员表现，数据科学赋能决策
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 |
|------|------|
| 预测可操作 | 提供具体比分/胜负预测，帮助用户做观赛和决策参考 |
| 模型透明 | 展示预测依据和置信度，避免"黑箱"感 |
| 多维覆盖 | 覆盖胜负/比分/球员/战术等多维度分析 |
| 准确率可验证 | 历史预测 vs 实际结果对比，建立公信力 |

#### ④ 今日比赛预测卡片

```
┌──────────────────────────────────────────────────────────────────┐
│  10:00 小组A                                                     │
│                                                                  │
│  🇺🇸 美国  vs  加拿大 🇨🇦                                        │
│                                                                  │
│  AI 预测:                                                        │
│  ┌──────────┬──────────┬──────────┐                              │
│  │  主胜    │  平局    │  客胜    │                              │
│  │  48%    │  26%    │  26%    │                              │
│  │  ████   │  ██     │  ██     │                              │
│  └──────────┴──────────┴──────────┘                              │
│                                                                  │
│  最可能比分: 2:1 (18%)                                           │
│  预期进球: 2.4 : 1.1                                             │
│  置信度: ★★★★☆ 78%                                              │
│                                                                  │
│  [详细分析 →]                                                    │
└──────────────────────────────────────────────────────────────────┘
```

| 元素 | 说明 |
|------|------|
| **胜负概率条** | 三栏(主胜/平局/客胜)，概率最高者高亮 |
| **最可能比分** | 取模拟中出现最频繁的比分 |
| **预期进球** | AI 预测的双方进球数期望值 |
| **置信度** | 五星评分+百分比，表示模型对预测的把握度 |
| **时间语义** | 赛前预测/赛中实时预测(动态更新) |
