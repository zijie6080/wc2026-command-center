# 我的收藏页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/favorites`
> **页面定位:** 用户个人观赛管理中心——收藏的球队/球员/比赛一站式访问
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 |
|------|------|
| 收藏聚合 | 球队/球员/比赛三类收藏统一管理 |
| 快捷入口 | 从收藏直接进入关注内容，减少导航成本 |
| 状态感知 | 关注球队的比赛状态、关注球员的数据变化一目了然 |
| 管理便捷 | 支持批量编辑和排序 |

### 2.2 模块详解

#### ④ 收藏内容区

**关注球队卡片：**

| 元素 | 说明 |
|------|------|
| **队徽+队名+FIFA排名** | 球队身份标识 |
| **下一场比赛** | 日期+对手+倒计时，最重要的动态信息 |
| **小组排名** | 当前小组排名 + 积分 + 进失球 |
| **操作** | [查看球队]→球队详情页 / [赛程]→赛程页筛选该队 / [⭐已收藏]→点击取消 |

**关注球员卡片：**

| 元素 | 说明 |
|------|------|
| **头像+姓名+国籍+号码** | 球员身份标识 |
| **本届数据** | 进球/助攻/评分，核心数据一目了然 |
| **数据变化** | 相比上次查看的变化(绿色▲/红色▼) |
| **操作** | [查看→]→球员详情页 |

**收藏比赛 — 未开始 vs 已结束：**

| 状态 | 卡片内容 |
|------|----------|
| **未开始** | 对阵+倒计时+场馆+[查看][取消收藏] |
| **已结束** | 比分+MVP信息+[战报][集锦][数据] |
