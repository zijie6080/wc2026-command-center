# 设置中心页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/settings`
> **页面定位:** 用户个人偏好管理中心——通知/显示/隐私/账号一站式配置
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 |
|------|------|
| 配置清晰 | 分组明确，每项设置有说明文字 |
| 即时预览 | 主题/语言等设置即时生效，所见即所得 |
| 通知精细化 | 支持按比赛/球队/事件类型细粒度控制 |
| 隐私可控 | 用户对数据使用有完全知情权和选择权 |

---

### 2.2 模块详解

#### ③ 左侧设置导航 (Settings Sidebar — 240px)

```
┌─────────────────────┐
│  ● 个人资料          │  ← 当前选中高亮
│    通知偏好          │
│    显示设置          │
│    语言与时区        │
│    关注管理          │
│    隐私设置          │
│    账号管理          │
│  ──────────────────  │
│  ← 返回首页          │
└─────────────────────┘
```

| 属性 | 说明 |
|------|------|
| **导航项** | 7 个设置分组 |
| **选中态** | 蓝色背景 + 左侧指示条 |
| **交互** | 点击切换右侧内容区；支持键盘 ↑↓ 切换 |
