# 球员详情页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/players/:id`
> **页面定位:** 一名球员的完整数据档案——世界杯赛事的专属数据视图
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|----------|
| 身份识别 | 进入页面 1 秒内识别球员身份 | 头图 + 姓名 + 国旗首屏可见 |
| 数据可读 | 多维数据以可视化方式呈现，避免纯表格 | 雷达图 + 柱状图占比 > 60% |
| 交叉导航 | 从球员页无缝跳转到比赛/球队/相似球员 | 相关链接 ≥ 4 个 |
| 分享友好 | 一键生成球员数据卡片分享 | 分享按钮首屏可见 |

| 按钮 | 交互行为 |
|------|----------|
| **⭐ 收藏** | 未收藏→点击收藏(⭐变实心黄色)；已收藏→点击取消(⭐变空心)。同步到"我的收藏"页 |
| **🔗 分享** | 弹出分享面板：生成球员数据卡片图片 → Twitter/Facebook/WhatsApp/复制链接/下载卡片 |
| **📥 导出数据** | 弹出格式选择：CSV（表格数据）/ JSON（原始数据）/ PDF（完整报告） |
| **📊 对比球员** | 打开球员选择器，选择另一名球员 → 跳转到对比视图 `/players/compare?id=xxx&id2=yyy` |

#### ③ 页内标签导航 (In-Page Tabs — 48px, sticky)

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│  ● 概览  │  比赛数据  │  比赛日志  │  雷达图  │  荣誉  │  新闻                   │
└─────────────────────────────────────────────────────────────────────────────────┘
```

| 标签 | 锚点 | 内容 |
|------|------|------|
| **概览** | `#overview` | 赛事数据面板 + 比赛日志（默认激活） |
| **比赛数据** | `#stats` | 详细统计表格（射门区域/传球分布/跑动热力图等） |
| **比赛日志** | `#matchlog` | 本届世界杯每场比赛的详细个人数据 |
| **雷达图** | `#radar` | 全屏雷达图 + 历史数据对比 + 联赛表现对比 |
| **荣誉** | `#honors` | 完整荣誉列表（时间线形式） |
| **新闻** | `#news` | 该球员相关新闻聚合 |

| 交互 | 行为 |
|------|------|
| **点击标签** | 平滑滚动到对应区域 |
| **滚动页面** | 标签自动高亮当前可视区域对应的标签（ScrollSpy） |
| **sticky 定位** | 滚动超过英雄区后固定在页面顶部（top: 56px，导航栏下方） |

## 五、交互行为汇总

### 5.1 页面级

| 交互 | 行为 |
|------|------|
| **面包屑** | 首页 > 球员 > Lionel Messi，点击跳转 |

| 交互 | 行为 |

| **点击新闻** | 跳转新闻详情页 `/news/:id` |
