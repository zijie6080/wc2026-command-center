# 历史比赛页原型设计 — World Cup 2026 Command Center

> **页面路径:** `/matches/history`
> **页面定位:** 所有已结束比赛的搜索与浏览中心——赛后复盘、数据查阅、MVP 回顾
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|----------|
| 快速检索 | 按球队/日期/阶段秒级定位目标比赛 | 搜索响应 < 300ms |
| 结果可扫读 | 每场比赛的比分+MVP+核心数据一瞥即得 | 单场比赛信息 < 3 行 |
| 深度入口 | 从列表一键进入比赛详情/球员详情 | 所有可点击元素均可跳转 |
| 数据丰富 | 不只是一个列表，而是赛后信息的聚合入口 | 每场展示 ≥ 5 项数据维度 |

#### ② 页面标题栏 (Page Title Bar — 56px)


| 元素 | 作用 |
|------|------|
| **🕐 历史比赛** | 页面标题，明确告知用户当前页面定位 |

#### ③ 搜索 & 筛选栏 (Search & Filter Bar — 56px, sticky)

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ ┌─────────────────────────┬─────────────────────────────────────────────────────┐│
│ │ 🔍 搜索球队、球员、日期 │  [小组赛▼] [全部小组▼] [全部月份▼] [最新优先▼] [🔄 重置] ││
│ └─────────────────────────┴─────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────────────────────────────┘
```

**搜索框：**

| 属性 | 说明 |
|------|------|
| **占位符** | "搜索球队、球员、日期..." |
| **搜索范围** | 球队名(中/英)、球员名、比赛日期(如"6月24日")、场馆名 |
| **自动补全** | 输入 ≥ 2 个字符后弹出建议列表，分"球队""球员""日期"三类 |
| **模糊匹配** | 支持拼音首字母、部分匹配 |

**筛选器：**

| 筛选器 | 选项 | 默认值 | 作用 |
|--------|------|--------|------|
| **阶段** | 全部 / 小组赛 / 1/16决赛 / 1/8决赛 / 1/4决赛 / 半决赛 / 三四名决赛 / 决赛 | 全部 | 按赛事阶段筛选 |
| **小组** | 全部 / A组 ~ L组 | 全部 | 按小组筛选(淘汰赛阶段自动禁用) |
| **月份** | 全部 / 6月 / 7月 | 全部 | 按月筛选 |
| **排序** | 最新优先 / 最早优先 / 进球最多 / 净胜球最大 | 最新优先 | 排序方式 |
| **🔄 重置** | 一键清空所有筛选条件 | — | 回到默认状态 |

## 五、空状态 & 边界场景

### 5.1 空状态

| 场景 | 展示 |

## 七、交互行为汇总

### 7.1 页面级

| 交互 | 行为 |
|------|------|
| **搜索框输入** | ≥ 2 字符弹出建议面板，Enter 键确认搜索 |
| **筛选器变更** | 即时过滤列表(前端)，无页面刷新 |
| **排序切换** | 列表即时重排 |
| **🔄 重置** | 清空搜索框 + 恢复所有筛选器默认值 |
| **日期分组折叠** | 点击日期标题折叠/展开，默认全部展开 |

### 7.2 卡片级

| 交互 | 行为 |
|------|------|
| **点击卡片主体** | 跳转比赛详情页 `/matches/:id` |
| **点击 ⚽ 进球球员** | 跳转球员详情页 `/players/:id` |
| **点击 ⭐ MVP** | 跳转球员详情页 |
| **点击 [📝 战报]** | 跳转比赛详情页"战报"标签 |
| **点击 [▶ 集锦]** | 展开嵌入视频或跳转集锦页 |
| **点击 [📊 数据]** | 展开完整统计表(页内手风琴) |
| **悬停卡片（桌面）** | 卡片轻微放大 + 加深阴影 |

### 7.3 键盘快捷键（桌面端）

| 快捷键 | 行为 |
|--------|------|
| `Ctrl+K` | 聚焦搜索框 |
| `Esc` | 清空搜索/关闭弹窗 |
| `T` | 切换紧凑模式 |
