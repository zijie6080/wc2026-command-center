# 赛程中心原型设计 — World Cup 2026 Command Center

> **页面路径:** `/schedule`
> **页面定位:** 完整赛程规划中心——帮助用户发现、筛选、规划观赛计划
> **设计版本:** v1.0 / 2026-06-04

---

## 一、设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|------|
| 全量可浏览 | 104 场比赛完整覆盖，不遗漏任何一场 | 任意比赛 ≤ 3 次点击可达 |
| 多维筛选 | 按日期/球队/小组/阶段灵活组合筛选 | 筛选切换 < 200ms |
| 观赛规划 | 用户可标记想看的比赛并导出到日历 | 提醒设置完成率 > 60% |
| 状态清晰 | 已结束/进行中/即将开始三种状态一目了然 | 颜色+图标双重编码 |

#### ② 页面标题栏 (Page Title Bar — 56px)

```

| 元素 | 作用 |
|------|------|
| **页面标题** | "📅 赛程中心"，明确页面定位 |
| **摘要信息** | 赛事全称 + 总比赛数 + 日期跨度 |
| **📥 导出日历** | 将当前筛选结果导出为 .ics 日历文件，支持 Google/Apple/Outlook 日历导入 |

**快捷视图按钮：**

| 按钮 | 作用 | 激活效果 |
|------|------|----------|
| **●今日** | 仅显示今天的比赛 | 蓝色填充，页面自动滚动到今天 |
| **明日** | 仅显示明天的比赛 | 蓝色填充 |
| **本周** | 显示本周(周一~周日)的全部比赛 | 蓝色填充 |
| **全部** | 显示全部 104 场比赛 | 蓝色填充 |

**筛选器：**

| 筛选器 | 选项 | 默认值 | 作用 |
|--------|------|--------|------|
| **🔍 搜索** | 自由输入 | 空 | 模糊搜索球队名(中/英)，支持拼音首字母 |
| **全部阶段** | 全部 / 小组赛第1轮 / 小组赛第2轮 / ... / 决赛 | 全部 | 精确到轮次 |
| **全部小组** | 全部 / A组~L组 | 全部 | 按小组筛选(淘汰赛自动禁用) |
| **全部球队** | 全部 / 48支球队逐一列出 | 全部 | 选择一支球队，仅显示其赛程 |
| **🔄 重置** | 一键清空所有筛选 | — | 回到全部比赛 + 今天 |

```

| 元素 | 作用 | 交互 |
|------|------|------|
| **◀ 月份切换** | 点击切换到上一月(5月→隐藏) | 点击展开月份下拉选择器 |
| **日期卡片** | 单个日期：日期/星期/比赛场次 | 点击选中 + 页面滚动到该日期 |
| **今天 (●●)** | 双圈高亮标识今天 | 默认选中 |
| **休赛日** | "休赛"灰色文字，背景减淡 | 可点击但无内容 |
| **开幕日** | 特殊标记"开幕"或"🏆决赛" | 视觉突出(金色边框) |
| **▶ 滚动** | 继续向右滚动查看后续日期 | 点击滚动 +7 天 |

## 五、交互行为汇总

### 5.1 页面级

| 交互 | 行为 |
|------|------|
| **快捷视图切换** | 点击今日/明日/本周/全部 → 日期导航条自动跳转 + 列表刷新 |
| **筛选器变更** | 即时过滤列表(前端)，无页面刷新 |
| **🔄 重置** | 清空所有筛选 + 回到"今日"视图 |
| **滚动加载** | 向下滚动自动加载后续日期(懒加载，每次 +5 天) |

### 5.2 卡片级

| 交互 | 行为 |
|------|------|
| **点击卡片主体** | 跳转比赛详情页(赛前视图) `/matches/:id` |
| **🔔 提醒我** | 未登录→引导登录；已登录→设置推送 → 加入"我的观赛计划" |
| **⭐ 收藏** | 收藏该比赛 → 加入"我的观赛计划" → 按钮变为实心黄色 ⭐ |
| **📅 添加到日历** | 生成 .ics 文件下载，或调用系统日历 API |
| **📝 前瞻(焦点战)** | 跳转比赛详情页"赛前前瞻"标签 |

### 5.3 键盘快捷键（桌面端）

| 快捷键 | 行为 |
|--------|------|
| `←` `→` | 日期导航条前后切换 |
| `T` | 跳转到今天 |
| `W` | 切换到"本周"视图 |
| `A` | 切换到"全部"视图 |
| `Esc` | 清除筛选 |
